\begin{abstract}
Machine-learning methods applied to detector waveforms can improve timing in time-of-flight positron emission tomography. This report evaluates the two waveform models retained in the final analysis pipeline: a proposed detector-shared antisymmetric multilayer perceptron (MLP) and the paired convolutional neural network (CNN) reference based on Onishi et al. Both models learn an event-by-event correction to a calibrated leading-edge-discrimination timing residual from the same pair of aligned detector waveforms. The comparison is performed on a short input window reproducing the Onishi timing region and on a wider waveform window, with final performance evaluated only on the permanent blind-test population. Energy- and timing-channel studies separate relative correction gain from absolute timing performance, while model-output correlation and gradient-based temporal sensitivity provide complementary information about the learned correction.
