    d(t)=s_1(t)-s_2(t)

\subsection{Shared 1-D CNN}

The model named \texttt{cnn} applies the same 1-D scorer \(g_\theta\) independently to the two detector waveforms and forms
\begin{equation}
    y_\theta = g_\theta(s_1)-g_\theta(s_2).
\end{equation}
This architecture therefore enforces detector-swap antisymmetry by construction.

\subsection{Joint 2-D CNN}

The model named \texttt{cnn\_2d} receives the detector pair as one stacked \([2,\mathrm{time}]\) input. The initial temporal block preserves the two detector rows, applying shared height-1 temporal filters independently to each row. A configurable later convolution then spans both detector rows once, fusing the detector axis from height 2 to height 1 before the remaining temporal blocks. The network predicts one timing correction directly, and detector-swap antisymmetry is not enforced by the architecture.

\subsection{Optional exploratory models}

\paragraph{Difference k-NN.}
The optional \texttt{difference\_knn} model uses the same waveform-difference representation \(s_1-s_2\) and Euclidean nearest-neighbour regression.

\paragraph{Fixed-position difference shapelets.}
The optional \texttt{difference\_shapelet} model uses learnable templates evaluated at fixed synchronized time supports of the waveform difference.
