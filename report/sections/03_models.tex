\section{Machine-learning timing correction}

The model comparison is designed as a controlled test of representation and physical structure rather than a broad model benchmark. The main paper therefore focuses on three models: a linear difference baseline, the proposed detector-shared CNN, and a more general joint CNN.

\subsection{Linear difference baseline}

The linear support vector regressor (SVR) receives the synchronized waveform difference
\begin{equation}
    d(t)=s_1(t)-s_2(t)
\end{equation}
and predicts the timing correction from a linear combination of temporal samples. It provides a compact control for determining how much of the correction can be represented without nonlinear feature extraction.

\subsection{Detector-shared 1-D CNN: physically constrained model}

The proposed shared CNN applies the same detector-level function \(g_\theta\) to both input waveforms:
\begin{equation}
    y_\theta = g_\theta(s_1)-g_\theta(s_2).
\end{equation}

Using one shared scorer imposes two structural constraints:
\begin{enumerate}
    \item the same learned detector response model is used for both signals;
    \item exchanging the two detector inputs changes only the sign of the prediction,
    \begin{equation}
        y_\theta(s_2,s_1)=-y_\theta(s_1,s_2).
    \end{equation}
\end{enumerate}

This factorized form is the primary physics-motivated model studied in the paper. It also provides a representation that is naturally compatible with reuse across detector pairs, although system-level scalability should only be claimed if separately demonstrated.

\subsection{Joint CNN: general pair-model comparator}

The joint model receives the two detector waveforms together as a stacked \([2,\mathrm{time}]\) input and directly predicts one correction:
\begin{equation}
    y_\theta=f_\theta(s_1,s_2).
\end{equation}

In the current implementation, the first temporal block preserves the two detector rows. A configurable later convolution spans both rows once, fusing the detector axis before the remaining temporal blocks. Unlike the shared model, detector-swap antisymmetry is not enforced.

The joint CNN is used as the flexible comparator: if the shared model reaches comparable CTR, the result supports the hypothesis that arbitrary pair-specific interactions are not required to obtain the timing correction.

\subsection{Controlled architecture comparison}

Where possible, the shared and joint CNNs should be compared with matched temporal channels, kernels, strides, dilations, pooling, dense head, optimizer, waveform window, training population, and validation criterion. The intended experimental variable is the pair representation:
\[
g_\theta(s_1)-g_\theta(s_2)
\quad\text{versus}\quad
f_\theta(s_1,s_2).
\]

\subsection{Information-localization tools}

Model interpretation is used to support, not replace, performance-based evidence. The CNN XAI output is based on mean absolute input gradients projected onto the retained waveform time axis;\footnote{K. Simonyan, A. Vedaldi, and A. Zisserman, \emph{Deep Inside Convolutional Networks: Visualising Image Classification Models and Saliency Maps}, ICLR Workshop, 2014.} the Linear SVR exposes the magnitude of its learned temporal coefficients.

The stronger information-localization test should combine:
\begin{enumerate}
    \item performance as the available waveform window is varied or ablated;
    \item XAI sensitivity as a function of time;
    \item consistency of the highlighted regions across bias voltage, board source, architecture, and waveform family where data permit.
\end{enumerate}
