The key question is not only which model gives the lowest CTR, but whether the detector-shared architecture retains the gain obtained by the more flexible joint model.

\subsection{Timing-information localization}

This section should investigate whether predictive timing information is confined to the conventional leading-edge region or remains available elsewhere in the waveform.

The preferred evidence combines a controlled window study with XAI:
\begin{itemize}
    \item evaluate CTR as the temporal extent of the ML input window is changed;
    \item compare the performance trend with the temporal sensitivity highlighted by the trained models;
    \item assess whether the same regions remain important across operating points and architectures.
\end{itemize}

\subsection{Timing-channel extension}

The same event-selection and correction framework is then applied using the dedicated second-stage timing waveform as the ML input. Energy-channel information remains the basis for photopeak selection, while timing-channel waveforms provide the timing features.

This section should report the absolute timing performance and the remaining ML correction gain. A smaller relative improvement than in the energy-channel study would not necessarily indicate a weaker method if the timing channel already provides a substantially better baseline CTR.
