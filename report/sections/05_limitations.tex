Gradient- or coefficient-based importance identifies regions to which the trained model is sensitive; it does not by itself prove that a waveform region carries causal timing information. \subsection{Limitations to assess}

Retain only limitations supported by the final study:
\begin{itemize}
    \item \textbf{Dataset and detector scope:} whether conclusions generalize beyond the measured detectors, board sources, bias voltages, and acquisition conditions.
    \item \textbf{Single holdout protocol:} sensitivity of model selection to the chosen train and validation split.
    \item \textbf{Validation reuse inside neural training:} neural early stopping uses validation RMSE while candidate ranking uses validation CTR on the same validation population.
    \item \textbf{Training-target filtering:} sensitivity to the selected target-range candidate and the fraction of training events retained.
    \item \textbf{Train-derived sample mask:} sensitivity to the 99\% constant-value threshold.
    \item \textbf{No final refit:} the validation-selected trained model is evaluated directly instead of being refitted on training plus validation.
    \item \textbf{Architecture matching:} any residual parameter-count or receptive-field differences between the shared and joint CNNs.
    \item \textbf{CTR statistics:} bootstrap stability and non-Gaussian or multimodal residual structure.
    \item \textbf{Interpretability:} temporal importance is model-dependent and should not be interpreted causally without ablation evidence.
\end{itemize}

\subsection{Possible next experiments}

\begin{enumerate}
    \item \textbf{Window ablation as primary information test:} systematically truncate or mask temporal regions and measure held-out timing performance.
    \item \textbf{Repeated-split robustness:} repeat model development across several development splits while preserving a final untouched test population.
    \item \textbf{Cross-board transfer, if compatible:} train on one front-end source and evaluate on the other to directly test domain robustness.
    \item \textbf{Detector-network scalability:} evaluate whether one shared detector scorer can be reused across more than one detector pair.
    \item \textbf{XAI stability:} quantify importance-profile variability across seeds, bias voltages, boards, and architectures.
\end{enumerate}
