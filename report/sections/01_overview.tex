\subsection{Experimental setup}

The waveform measurements were performed with two opposing detector modules and a $^{22}$Na positron-emitting source centered between them. Each detector module is based on a SiPM coupled to a LYSO scintillation crystal with dimensions $2\times2\times3\,\mathrm{mm}^3$. The experimental layout is therefore a symmetric two-detector coincidence setup, with the source positioned between the two modules.

Each detector front end provides two analog waveform outputs:
\begin{itemize}
    \item an \textbf{energy channel}, taken after the first amplification stage and used for energy-based event selection as well as, when required, timing analysis;
    \item a \textbf{timing channel}, taken after a second amplification stage specifically intended to preserve timing information.
\end{itemize}

The full analog waveforms are digitized with an oscilloscope. The presentation dataset documents \SI{100}{ns} acquisition windows sampled at \SI{80}{GS/s}, with waveform measurements spanning the \SIrange{45}{49}{V} bias-voltage region.

Two waveform dataset sources are considered in this report:
\begin{itemize}
    \item the \textbf{UC-board dataset}, acquired with the front-end board developed by the University of Chicago group;
    \item the \textbf{FBK-board dataset}, acquired with the FBK front-end board.
\end{itemize}

The purpose of keeping the two sources separate in the report is to make the acquisition hardware explicit when comparing event statistics and timing performance. The analysis pipeline described in the following sections is applied to full waveform data only.
