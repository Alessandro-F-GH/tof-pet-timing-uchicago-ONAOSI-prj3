\section{Introduction and scientific scope}

\subsection{Motivation}

Previous waveform-based machine-learning studies have shown that learned corrections can improve coincidence timing resolution with respect to standard timing estimators. The objective of this work is not only to seek a lower CTR, but to characterize \emph{how} the correction is represented and \emph{where} useful timing information is located in the detector waveform.

A fully general pair model can learn arbitrary relationships between the two detector signals. Such flexibility is useful as a performance reference, but it does not impose the detector-exchange structure expected for a relative timing correction and it is less naturally reusable across detector pairs. This work therefore studies a detector-shared formulation in which the same function is applied to both detector waveforms and the final correction is formed from their difference.

At the same time, the study uses waveform windows larger than those typically considered in the earlier project baseline and combines performance measurements with model-interpretability tools. The goal is to investigate whether timing-relevant information is concentrated around the conventional leading edge or whether additional waveform regions contribute to the learned correction.

A second experimental axis is provided by the front-end readout itself. In addition to the energy-channel waveform, the detector board provides a second-stage timing-channel signal specifically designed for timing. The energy channel is used as the main methodological test bed for comparing model structures and studying information localization; the same framework is then applied to the dedicated timing channel, where the best absolute timing performance is expected to be obtained.

\subsection{Research questions}

The study is organized around three primary questions:

\begin{enumerate}[label=\textbf{Q\arabic*.}]
    \item \textbf{Physical structure:} can a detector-shared correction
    \begin{equation}
        \hat y = g_\theta(s_1)-g_\theta(s_2)
    \end{equation}
    retain the timing performance of a more general joint model
    \begin{equation}
        \hat y = f_\theta(s_1,s_2),
    \end{equation}
    while enforcing detector-swap antisymmetry by construction?

    \item \textbf{Information localization:} which temporal regions of the waveform contain information useful for correcting the timing estimate, and are the regions highlighted by XAI consistent with performance changes obtained by varying or ablating the input window?

    \item \textbf{Dedicated timing signal:} does the same waveform-correction framework remain effective when applied to the second-stage timing-channel waveform rather than the energy-channel waveform?
\end{enumerate}

\subsection{Contributions to be demonstrated}

The intended contribution is broader than a single best-CTR result:
\begin{itemize}
    \item a controlled comparison between a physically constrained detector-shared model and a general joint detector-pair CNN;
    \item a timing-information study combining extended waveform windows, performance ablations, and XAI;
    \item application of the same correction framework to both the energy-channel and dedicated timing-channel waveforms;
    \item CTR evaluation on a permanent blind-test population, with bootstrap uncertainty and explicit separation between model selection and final evaluation.
\end{itemize}
