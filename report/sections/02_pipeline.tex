\subsection{Native-time waveform preprocessing}

For accepted events, the pipeline decodes and orients the waveform samples, applies detector-specific configured vertical limits, crops around the selected main trigger, and preserves the native acquisition time grid. The current pipeline does not apply denoising or event-wise baseline subtraction.

\subsection{Reference timing, calibration, and ML target}

LED thresholds are evaluated on development data. If CFD is enabled, it is treated as an additional standard timing reference. The selected LED crossing time is linearly interpolated.

The channel calibration used by the ML target is estimated from training data:
\begin{equation}
    \widehat{C}_{12}
    =
    \operatorname{mean}_{\mathrm{train}}\!\left(\Delta t_{\mathrm{LED}}\right)
    -
    \mathrm{TOF}.
\end{equation}

The supervised target stored by the current pipeline is
\begin{equation}
    y_{\mathrm{target}}
    =
    \Delta t_{\mathrm{LED}}
    -
    \mathrm{TOF}
    -
    \widehat{C}_{12}.
\end{equation}

\subsection{ML waveform construction and normalization}

The ML window is materialized relative to the native sample nearest the interpolated selected LED crossing. The configured temporal subsampling is then applied. Waveforms are transformed with detector-specific physical vertical limits rather than event-wise scaling.

The current training pipeline also applies one shared temporal binary mask to both detector channels. The mask is derived from training events only; a time sample is discarded when both channels independently take one identical normalized value in at least 99\% of the training events.

\subsection{Training, hyperparameter search, and model selection}

Candidate models are fitted on the training split. The configured symmetric target-range filter is applied to training events only. Candidate models are ranked using validation CTR. Neural models may use validation RMSE internally for early stopping; this is distinct from the final candidate-ranking metric. The validation-selected trained model is used directly, without a final refit.

\subsection{CTR definition and uncertainty}

The current study uses the Gaussian-equivalent shortest empirical coverage interval as the canonical CTR estimator. For coverage fraction \(p\), the narrowest empirical interval containing \(\lceil pN\rceil\) finite residuals is found and converted to the equivalent Gaussian FWHM scale. The configured default coverage is \(p=0.90\). CTR uncertainty is evaluated by event bootstrap.

For an ML model with prediction \(y_\theta\), the final timing residual is
\begin{equation}
    r_{\mathrm{ML}} = y_{\mathrm{target}} - y_\theta.
\end{equation}
