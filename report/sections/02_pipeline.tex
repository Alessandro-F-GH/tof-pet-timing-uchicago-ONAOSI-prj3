\section{Waveform analysis framework}

This section describes the common analysis applied before comparing machine-learning (ML) architectures or waveform families. Implementation details are included only where they affect scientific reproducibility, leakage control, or the definition of the timing residual.

\subsection{Data partitioning and leakage control}

The original event population is divided into a permanent development population and a blind-test population before fitted selection criteria are derived. The development population is further separated into training and validation subsets for model development. Fitted event-selection criteria, calibration quantities, model hyperparameters, target-range filtering, and the train-derived sample mask are determined without using the blind-test population.

\subsection{Event selection}

The event-selection chain can include:
\begin{itemize}
    \item finite energy amplitudes in both detectors;
    \item a two-detector energy-photopeak requirement;
    \item a valid pulse / main-hit requirement on the waveform family used for timing;
    \item a time-over-threshold (ToT) selection when timing-channel waveforms are analyzed;
    \item an optional baseline root-mean-square (RMS) requirement.
\end{itemize}

Parameters fitted from event distributions are determined on development data and frozen before application to the blind-test population. Energy information is retained as the common event-selection reference even when timing-channel waveforms are used as the ML input.

\subsection{Native-time waveform preprocessing}

For accepted events, the pipeline decodes and orients the waveform samples, applies detector-specific configured vertical limits, crops around the selected main trigger, and preserves the native acquisition time grid. No denoising or event-wise baseline subtraction is applied in the current pipeline.

\paragraph{Rationale.}
Preserving native waveform samples avoids introducing a separate filtering model before the timing study. The ML analysis therefore operates on the measured waveform shape after only the deterministic acquisition-domain transformations required for a consistent input representation.

\subsection{Reference timing, calibration, and learning target}

Leading-edge discriminator (LED) thresholds are evaluated on development data. If a constant-fraction discriminator (CFD) is enabled in a reported study, it is treated as an additional standard timing reference. The selected LED crossing time is linearly interpolated.\footnote{L. Y. Chang et al., \emph{A Time-Walk Correction Method for PET Detectors Based on Leading Edge Discriminators}, \textit{IEEE Transactions on Radiation and Plasma Medical Sciences}, 2017.}

The fixed inter-channel calibration is estimated from training data:
\begin{equation}
    \widehat{C}_{12}
    =
    \operatorname{mean}_{\mathrm{train}}\!\left(\Delta t_{\mathrm{LED}}\right)
    -
    \mathrm{TOF}.
\end{equation}

The supervised learning target is
\begin{equation}
    y_{\mathrm{target}}
    =
    \Delta t_{\mathrm{LED}}
    -
    \mathrm{TOF}
    -
    \widehat{C}_{12}.
\end{equation}

The ML model therefore learns a correction to a conventional timing estimate rather than reconstructing TOF directly from an unconstrained label.

\subsection{ML waveform representation}

The ML window is materialized relative to the native sample nearest the selected interpolated LED crossing. The configured temporal subsampling is then applied. Waveforms are normalized with detector-specific physical vertical limits rather than event-wise scaling.

A common binary temporal mask is learned from the training split only and applied identically to both detector inputs. A time sample is removed when both channels independently take one identical normalized value in at least 99\% of training events. This removes consistently cropped or clipped regions without allowing validation or blind-test events to define the input representation.

\subsection{Training and model selection}

Candidate models are fitted on the training split. The configured symmetric target-range filter is applied to training events only. Candidate hyperparameters are ranked by validation CTR. Neural models may use validation root-mean-square error (RMSE) internally for early stopping, which is distinct from the validation-CTR criterion used for candidate selection. The selected trained model is then evaluated directly on the permanent blind-test population without a final refit.

\subsection{CTR estimator}\label{sec:ctr-estimator}

The canonical CTR is the Gaussian-equivalent shortest empirical coverage interval. For coverage fraction \(p\), the narrowest interval containing \(\lceil pN\rceil\) finite residuals is found and converted to the Gaussian-equivalent full width at half maximum (FWHM) scale. CTR uncertainty is evaluated by event bootstrap.

For a model prediction \(y_\theta\), the final corrected residual is
\begin{equation}
    r_{\mathrm{ML}}=y_{\mathrm{target}}-y_\theta.
\end{equation}
