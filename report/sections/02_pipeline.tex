\section{Waveform analysis framework}

This section summarizes the main analysis steps applied to the selected waveforms before model comparison and final timing evaluation.

\subsection{Data partitioning}

The data are divided into development and blind-test populations before model development. The development data are then separated into training and validation subsets used for fitting models and selecting hyperparameters, while the blind-test population is reserved for the final timing evaluation.

\subsection{Event selection}

Event selection is used to define a clean coincidence population before timing analysis. The common energy-channel selection identifies events in the photopeak region for both detectors. For timing-channel studies, an additional time-over-threshold (ToT) selection is used to isolate the main timing-pulse population. An optional baseline root-mean-square (RMS) requirement can be applied to reject events with abnormal pre-pulse noise.

\subsection{Waveform preparation}

Selected waveforms are brought to a common orientation and restricted to the analysis region around the main pulse. The native acquisition sampling is preserved, while fixed detector-specific amplitude limits provide a consistent normalization across events.

\subsection{Reference timing, calibration, and learning target}

Leading-edge discrimination (LED) is used as the reference timing estimator for the waveform analysis. For each detector, the arrival time is obtained from the interpolated threshold crossing of the rising edge. LED provides a simple and widely used waveform-based timing reference, while retaining the amplitude-dependent time-walk effects that the machine-learning correction is intended to reduce.\footnote{L. Y. Chang et al., \emph{A Time-Walk Correction Method for PET Detectors Based on Leading Edge Discriminators}, \textit{IEEE Transactions on Radiation and Plasma Medical Sciences}, 2017.}

\todo{Add a concise reference or motivation for choosing LED as the common baseline for both energy- and timing-channel studies, and state the threshold-selection procedure used in the final analysis.}

A fixed inter-channel timing offset is estimated from the training population:
\begin{equation}
    \widehat{C}_{12}
    =
    \operatorname{mean}_{\mathrm{train}}\!\left(\Delta t_{\mathrm{LED}}\right)
    -
    \mathrm{TOF}.
\end{equation}

The supervised target is then defined as
\begin{equation}
    y_{\mathrm{target}}
    =
    \Delta t_{\mathrm{LED}}
    -
    \mathrm{TOF}
    -
    \widehat{C}_{12}.
\end{equation}

The model therefore learns the event-by-event correction to the LED timing difference rather than predicting TOF directly.

\subsection{Machine-learning input}

The machine-learning (ML) input consists of synchronized waveform windows referenced to the selected LED crossing. The same temporal samples are used for the two detectors. A training-derived binary mask removes regions that are effectively constant in both input channels, avoiding consistently clipped or cropped samples that carry no event-dependent information.

\subsection{Model development}

Models are trained on the training population and selected using validation performance. A symmetric target-range requirement may be applied to the training population to reduce the influence of extreme timing residuals during fitting. Neural-network training uses validation root-mean-square error (RMSE) for early stopping, while candidate configurations are ranked using validation CTR.

\subsection{CTR estimator}\label{sec:ctr-estimator}

Coincidence timing resolution (CTR) is evaluated from the distribution of the timing residuals.\footnote{S. Surti, \emph{Update on Time-of-Flight PET Imaging}, \textit{Journal of Nuclear Medicine}, 56(1), 98--105, 2015, doi:10.2967/jnumed.114.145029.} The analysis uses the Gaussian-equivalent shortest empirical coverage interval: for a coverage fraction \(p\), the narrowest interval containing \(\lceil pN\rceil\) finite residuals is converted to the equivalent Gaussian full width at half maximum (FWHM). The statistical uncertainty is estimated by event bootstrap.

For a model prediction \(y_\theta\), the corrected residual is
\begin{equation}
    r_{\mathrm{ML}}=y_{\mathrm{target}}-y_\theta.
\end{equation}
