\section{Experimental setup and waveform datasets}

\subsection{Detector system}

The waveform measurements were performed with two opposing detector modules and a $^{22}$Na positron-emitting source centered between them. Each detector module is based on a silicon photomultiplier (SiPM) coupled to a lutetium-yttrium oxyorthosilicate (LYSO) scintillation crystal with dimensions $2\times2\times3\,\mathrm{mm}^3$.

Each detector front end provides two analog waveform outputs:
\begin{itemize}
    \item an \textbf{energy channel}, taken after the first amplification stage and used for energy-based event selection and, in the energy-waveform study, timing correction;
    \item a \textbf{timing channel}, taken after a second amplification stage specifically designed for timing.
\end{itemize}

The full analog waveforms are digitized with an oscilloscope using \SI{100}{ns} acquisition windows sampled at \SI{80}{GS/s}, with measurements spanning the \SIrange{45}{49}{V} bias-voltage region.


\subsection{Dataset}

The measurements are organized into two waveform datasets acquired with different front-end boards. The University of Chicago (UC) board dataset uses the front-end developed by the University of Chicago group, while the Fondazione Bruno Kessler (FBK) board dataset uses the FBK front end. Keeping the two sources separate allows the event statistics and timing results to be reported together with the corresponding acquisition hardware.
