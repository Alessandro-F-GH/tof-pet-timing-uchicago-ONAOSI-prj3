\section{Model architectures and training settings}
\label{app:spaces}
The following model families represent different assumptions about how waveform information can correct LED timing. Their scientific motivation and detector-pair formulations are described before the configured hyperparameter tables.

\subsection{Linear ridge regression}
Linear models provide a computationally inexpensive baseline
for testing whether a weighted combination of waveform samples
is sufficient for timing correction. The direct estimator uses
independent weights on the concatenated detector waveforms
and an intercept. The shared estimator instead applies common
weights to the sample-wise waveform difference, without an
intercept, enforcing detector-exchange antisymmetry.
By linearity, the shared correction can be written as
\begin{equation}
h(s_1,s_2)=\mathbf{w}^{T}(s_1-s_2)
=\mathbf{w}^{T}s_1-\mathbf{w}^{T}s_2.
\end{equation}
Thus, although the model is trained on waveform differences,
the same fitted weights can be applied independently to each
detector waveform, with only the resulting scalar scores
subtracted. Ridge regularization limits sensitivity to highly
correlated samples. Its strength is selected by internal
leave-one-out cross-validation minimizing mean squared error
(MSE), rather than the outer CTR-based selection.
\subsection{Convolutional neural networks}
Convolutional neural networks (CNNs) are established waveform-timing models, including for LED correction~\cite{onishi2022,loignon2025}. 
Their temporal filters exploit local waveform structure with weights shared across sample positions. 
The Onishi-inspired direct CNN combines the detector dimension in the first convolution and predicts a joint correction. 
The independent CNN uses separately parameterized temporal backbones and scalar heads for the two detector signals, then subtracts the outputs. 
The shared CNN uses one backbone and head for both signals, imposing the antisymmetric correction. 
Comparing these two variants tests the effect of detector-level parameter sharing.

\subsection{Multilayer perceptrons}
Because the waveforms are aligned to their individual LED crossings, relevant features occur at approximately consistent input positions, 
so translation-invariant representations are not necessarily required. A direct dense multilayer perceptron (MLP) regresses 
on the concatenated detector waveforms. 
The shared MLP applies a single dense network $g_\theta$ to
each detector waveform independently, using identical learned
parameters. The correction is obtained by subtracting the
two scalar outputs:
\begin{equation}
h_\theta(s_1,s_2)
= g_\theta(s_1)-g_\theta(s_2).
\end{equation}
The network is trained end-to-end on waveform pairs, minimizing
the prediction error of the resulting correction against the
supervised timing target. Both branches contribute to updating
the same parameters, thereby enforcing detector-exchange
antisymmetry throughout training and inference.

The shared locally connected MLP preserves temporal neighborhoods without sharing convolutional filters across positions. Two successive layers have independent kernels at each temporal position, followed by a dense detector scorer. An odd, smoothly bounded transformation is applied to the score difference, limiting correction amplitude while preserving antisymmetry. Local connectivity provides an intermediate architectural assumption between dense and convolutional processing~\cite{elsayed2020}.

\subsection{MiniRocket feature regression}
MiniRocket is an efficient, largely deterministic convolutional feature transformation developed for time-series classification~\cite{minirocket2021}. We use its features for timing-error regression with ridge regularization. The direct model applies a multivariate MiniRocket transform jointly to the two signals; the shared model applies a common univariate transform to each detector and regresses on their feature difference, without an intercept. Feature transforms and scaling are fitted on the calibration acquisition and fixed before supervised fitting. Unlike the two linear ridge estimators, MiniRocket models select ridge regularization using outer CTR-based cross-validation.

\subsection{Neural training procedures}
Dense MLPs, the locally connected MLP and temporal CNNs minimize root mean squared error (RMSE) using an internal training holdout for early stopping. The shared dense MLP uses Nesterov stochastic gradient descent; the other models in this group use Adam. The Onishi-inspired paired CNN instead minimizes MSE using Adam and a fixed epoch schedule without an internal early-stopping holdout. For all these neural models, the hyperparameters are selected using mean held-out coincidence timing resolution (CTR) in the three common outer folds, even though the fitting loss is squared-error-based.
