# Manuscript table fragments

Every table is stored as `report/tables/<type>/<table_name>.tex` and included from
section files or a board-specific results wrapper.

- `datasets/`: one acquisition table and one selected-event table per UC/FBK board.
- `models/`: estimator inventory, containing architecture descriptions only.
- `results/`: separate CTR placeholders per board, mode and window; board wrappers
  contain only `\input` commands.
- `hyperparameters/`: configured spaces generated by `report/generate_appendix.py`.
- `libraries/`: model and supporting library requirements.

Selected-event fragments are produced automatically by waveform batch reporting.
Copy only fragments belonging to the analysis described in the manuscript.
A dash marks unavailable data; zero is reserved for a measured empty population.
All result entries are placeholders until the matching experiments are available.
