\section{Machine-learning model and evaluation pipeline}

\subsection{Shared detector model}

The machine-learning model estimates an event-by-event correction to the calibrated LED timing residual defined in the previous section.

A single detector scorer \(g_\theta\) is shared between the two detector branches. 
For an aligned detector waveform \(s\), the function

\begin{equation}
    g_\theta(s)
\end{equation}

produces one scalar score. The same function, with the same parameters \(\theta\), is applied independently to the two detector waveforms 
\(s_1\) and \(s_2\).

The unbounded pair correction is then defined as

\begin{equation}
    z_\theta(s_1,s_2)
    =
    g_\theta(s_1)-g_\theta(s_2).
\end{equation}

Because the same scorer is used for both detectors, exchanging the two detector signals changes only the sign of the correction:

\begin{equation}
    z_\theta(s_2,s_1)
    =
    -z_\theta(s_1,s_2).
\end{equation}

The detector-exchange antisymmetry is therefore imposed directly by the model architecture rather than learned from the training data.


\subsection{Locally connected multilayer perceptron}

The detector scorer \(g_\theta\) is implemented as a locally connected multilayer perceptron (LC-MLP).

In a locally connected layer, each unit receives input only from a contiguous temporal neighborhood of the waveform. 
Unlike a convolutional neural network (CNN), however, the weights are not shared across different temporal positions. 
The model therefore preserves local temporal structure while allowing different regions of the aligned waveform to learn 
different transformations~\cite{elsayed2020,amit2019}.

This property is particularly suitable for the present application because all waveforms are aligned to the LED crossing. 
Consequently, the position of a feature relative to the crossing has a fixed physical meaning, and temporal translation invariance is not required.

The detector scorer contains two successive locally connected layers, followed by a fully connected layer with 32 hidden units and a scalar output. 
Both locally connected layers use kernel size \(k=3\) and stride \(s=1\), so neighboring units operate on overlapping temporal regions.

\subsection{Bounded timing correction}

The raw score difference \(z_\theta\) is converted into the final model correction using a smooth bounded transformation:

\begin{equation}
    \widehat{y}
    =
    C
    \tanh\left(
        \frac{z_\theta(s_1,s_2)}{C}
    \right),
\end{equation}

where \(C\) defines the maximum correction magnitude. In the present configuration,

\begin{equation}
    C = \SI{150}{ps}.
\end{equation}

The final model prediction therefore satisfies

\begin{equation}
    |\widehat{y}| < C.
\end{equation}

Bounding the correction prevents anomalous or out-of-distribution waveforms from producing arbitrarily large timing adjustments. 
It also limits the model's ability to fit rare events with very large LED timing errors, which would otherwise contribute strongly 
to the training loss.

The transformation preserves detector-exchange antisymmetry because the hyperbolic tangent is an odd function:

\begin{equation}
    \widehat{y}(s_2,s_1)
    =
    -\widehat{y}(s_1,s_2).
\end{equation}

For raw corrections much smaller than \(C\), the hyperbolic tangent is approximately linear so:

\begin{equation}
    |z_\theta| \ll C
    \implies
    \widehat{y}
    \simeq
    z_\theta(s_1,s_2).
\end{equation}

The bound therefore mainly affects unusually large predictions, while leaving small corrections approximately unchanged.

Finally, the corrected timing residual is obtained by subtracting the predicted correction from the calibrated LED residual:

\begin{equation}
    r_{\mathrm{corr}}
    =
    y_{\mathrm{target}}-\widehat{y}.
\end{equation}

\subsection{Comparison strategy}

The LC-MLP is evaluated using the two waveform windows defined in the preprocessing section.

The shorter Onishi window provides a reference configuration for a direct comparison with the paired CNN proposed by Onishi et al.~\cite{onishi2022}. 
The wide window instead tests whether additional temporal information outside the region immediately surrounding the LED crossing improves the correction.

The Onishi CNN has already been implemented in the analysis pipeline, but a complete comparison has not yet been performed because the model is 
substantially more computationally expensive to train than the LC-MLP.

In the planned comparison, the Onishi CNN and the shared antisymmetric LC-MLP will be evaluated using the same selected events, LED definition, 
data split, and waveform window. Comparing the two models using the Onishi window will isolate differences due to the model architecture, 
while repeating the comparison with the wide window will show whether either architecture benefits from the additional temporal information.


\subsection{Training and blind evaluation}

For the present study, the LC-MLP architecture and training configuration are fixed before the final performance evaluation.

The selected events are divided into two populations: \(50\%\) development data, used to train the model, and the remaining \(50\%\) 
used only for the final performance evaluation. The blind population is therefore never used to adapt the model architecture or training parameters.

The purpose of the current protocol is to evaluate a fixed model configuration rather than to perform an exhaustive hyperparameter optimization. 
Model selection is particularly challenging for these datasets because CTR estimates are statistically noisy. A reliable comparison between 
different hyperparameter configurations would require a sufficiently large validation population, reducing the number of events available for model 
training.

A possible future strategy is therefore to acquire or construct a larger dataset under a fixed experimental condition, 
for example at a single bias voltage, and use it specifically for model selection. A dedicated validation set or cross-validation 
could then be used for hyperparameter optimization while preserving an independent blind test population for the final evaluation.


\subsection{LED-threshold treatment}

The LED threshold is treated as part of the conventional timing estimator rather than as a model hyperparameter optimized using the blind test data.

For the main voltage studies, a fixed LED threshold of \SI{15}{mV} above the event baseline is used.

In addition, a separate threshold scan is performed for one representative dataset of each board and waveform mode. At each threshold value, 
both the uncorrected LED CTR and the LC-MLP-corrected CTR are evaluated. This makes it possible to study how the learned waveform correction 
depends on the choice of the initial LED timing reference.
