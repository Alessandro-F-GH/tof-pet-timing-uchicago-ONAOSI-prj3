\section{Datasets and results}

The results are reported separately for the University of Chicago (UC) and Fondazione Bruno Kessler (FBK) front-end boards and for the energy- and timing-channel waveform modes. For each configuration, the fixed-threshold results are shown for both the Onishi input window and the wider input window. A separate LED-threshold scan is reported for one representative bias-voltage dataset in each board/mode combination.
