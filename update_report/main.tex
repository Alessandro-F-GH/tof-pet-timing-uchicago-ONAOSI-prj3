\begin{abstract}
Time-of-flight positron emission tomography (TOF-PET) benefits directly from improved coincidence timing resolution. 
This update summarizes a waveform-based machine-learning approach for correcting leading-edge timing using the full detector waveform. 
The proposed model applies the same detector-level scorer to the two aligned waveforms and combines the two scores antisymmetrically.
The current model uses locally connected temporal processing instead of the convolutional neural networks commonly adopted in previous
 waveform-based TOF-PET studies.
